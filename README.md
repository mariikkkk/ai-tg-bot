# Мем-бот для беседы 🤡

Telegram-бот, который живёт в вашей беседе как ещё один участник: запоминает фотки, видео, кружочки
и сообщения, клепает из них мемы и тикток-эдиты, отвечает по-живому в вашей манере, помнит историю чата,
сам пишет первым и узнаёт друзей на фото.

Живые ответы идут **через твою подписку — Claude или ChatGPT**, без API-ключей: бот вызывает
залогиненный Claude Code (`claude -p`) или Codex CLI (`codex exec`). Без них бот тоже работает —
мемами и бредом цепей Маркова по вашему же чату.

**Что умеет:**
- мемы из фоток и видео чата: демотиваторы, Impact сверху/снизу, подписи на плашке, «пережаренные»;
  подписи придумывает ИИ, глядя на картинку и разговор;
- тикток-эдиты «фонк-велосити» из ваших фоток, видео и кружочков — нарезка точно под бит, замедления, вспышки;
- отвечает, когда зовут по имени (в любом падеже, без тега), и на продолжение разговора; ставит реакции,
  кидает стикеры из тех, что в ходу в чате, иногда говорит голосом с мемными эффектами;
- **долгая память:** читает всю историю чата и ведёт «летопись» — клички, приколы, истории — и к месту на неё ссылается;
- **пишет первым:** запоминает планы («завтра экзамен») и потом спрашивает, как прошло; зовёт пропавших;
- **характер:** настроение, отношения с каждым (от «вечный бэф» до «любимчик»), своя жизнь по легенде —
  распорядок дня и события, которые продолжаются день за днём;
- **узнаёт в лицо** тех, кто сам записался (`/face`) — локально, без облака;
- понимает голосовые и кружочки, знает свежие мемы, кидает картинки из интернета и ролики из Shorts;
- работает только в беседах, которые разрешил хозяин.

## Быстрый старт

Нужны: Python 3.11+, Node.js (для роликов с YouTube и чтобы поставить Claude Code / Codex), компьютер или
сервер, который будет постоянно включён. ffmpeg ставить не нужно — он приезжает с пакетом `imageio-ffmpeg`.

### 1. Создать бота
1. [@BotFather](https://t.me/BotFather) → `/newbot` → получить токен. Имя бота в Telegram — это его имя в чате.
2. **Обязательно:** `/setprivacy` → выбрать бота → **Disable**. Иначе в группе бот видит только команды.
   Если бот уже в чате — удалить и добавить заново после смены настройки.

### 2. Поставить
```bash
git clone <этот репозиторий> meme-bot && cd meme-bot
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
```
В `.env` вписать `BOT_TOKEN` и `OWNER_ID` — свой Telegram id (узнать у [@userinfobot](https://t.me/userinfobot)).

### 3. Подключить подписку (одну из двух)

**Claude (Pro / Max)** — [Claude Code](https://docs.anthropic.com/en/docs/claude-code):
```bash
npm install -g @anthropic-ai/claude-code
claude                  # войти своим аккаунтом Claude, потом выйти (/exit)
```

**ChatGPT (Plus / Pro)** — [Codex CLI](https://github.com/openai/codex):
```bash
npm install -g @openai/codex
codex login             # Sign in with ChatGPT
```
и в `.env`: `AI_PROVIDER=codex` (модель — `CODEX_MODEL`, по умолчанию — как у Codex).

По умолчанию (`AI_PROVIDER=auto`) бот берёт то, что найдёт, сначала Claude Code.

### 4. Запустить
```bash
.venv/bin/python bot.py
```
Добавь бота в беседу сам — она разрешится сразу. Хоть раз напиши боту `/start` в личку, чтобы он мог
спрашивать тебя, если его добавят куда-то ещё. При первом запуске бот сам докачает стартовые треки для эдитов
и модели для лиц.

### 5. Своя легенда (по желанию)
Бот играет персонажа с легендой — образец в [`persona.example.txt`](persona.example.txt) (пацан 19 лет из Балашихи,
шаурмечная, заочка, кот). Чтобы своя — скопировать в `persona.txt` и переписать: кто он, где живёт, чем занят,
семья, мечты. По легенде строятся его характер и «жизнь» — распорядок дня и события.

## Живые ответы: что нужно знать

- У Claude Code и Codex в боте отключены инструменты, команды, MCP, плагины, поиск и твои настройки;
  каждый вызов — в пустой временной папке. То, что пишут в чате, не может заставить их что-то выполнить на компьютере.
- В модель уходят: правила стиля чата (посчитаны по переписке), куски переписки с именами, последние ~30 сообщений,
  летопись, а для мемов и стикеров — сами картинки. Предупреди друзей.
- Неизменная часть промпта (~14 тыс. токенов) держится одинаковой, чтобы провайдер брал её из кэша — дешевле
  и быстрее. В логе у каждого ответа видно, сколько ушло из кэша.
- Лимиты подписки общие с твоей обычной работой в Claude / ChatGPT. `AI_MAX_PER_HOUR` ограничивает живые ответы
  в час на беседу; сверх лимита бот отвечает мемами.
- Подписки Claude и ChatGPT по правилам — для личного пользования. Бот, который отвечает целой беседе, —
  серая зона; строго по правилам — это API-ключ.
- Поддержка ChatGPT (Codex) новая: проверена на подменённом CLI и на разборе аргументов настоящим Codex,
  но не в живом чате. Если что-то не так — смотри лог и пиши issue.

## Где можно бота

Бот ходит в твою подписку и тратит твои деньги, поэтому где ему работать — решаешь ты (`OWNER_ID` в `.env`).

- Добавили в незнакомую беседу — бот молчит, ничего не запоминает и пишет тебе в личку
  «Меня добавили в «…» — разрешить?» с кнопками ✅ / 🚫. На 🚫 — выходит.
- Добавил ты сам — беседа разрешена сразу. `/chats` в личке — все беседы и кнопки.
- В личке бот отвечает тебе и участникам разрешённых бесед, остальным — молчит.
- Без `OWNER_ID` бот работает везде.

## Память и инициатива

- **Летопись.** Бот читает переписку (в том числе импортированную историю) и ведёт «летопись» беседы: кто есть кто,
  приколы и словечки, запомнившиеся истории, что происходит сейчас — и к месту на неё ссылается.
  Каждую ночь (4–7 утра) дописывается тем, что было за день. Посмотреть: `/lore`.
  Не записывается: пошлятина и флирт, внешность, отношения, здоровье, политика, неприятности, фамилии и адреса,
  а также «закулисье» — как настроен бот (проход-чистка + фильтр стоп-слов).
- **Планы друзей.** Раз в пару часов бот выискивает, у кого что намечено (экзамен, поездка, собеседование),
  и потом сам спрашивает: «Катя, ну че, сдала?». Ответишь ему без тега — поймёт, что это ему.
- **Пропавшие.** Кто писал, но молчит 6+ дней, пока чат живой, — бот позовёт (одного и того же — раз в две недели).
- **Время.** Бот знает, какой сейчас день и час.
- Пишет первым только с 11:00 до 22:30, не больше 3 раз в сутки и не чаще раза в полтора часа.
  `INITIATIVE=0` — не писать первым.
- **Кто есть кто:** `/name ник = имя` — у людей бывают разные ники в разных местах (в экспорте истории и вживую).

## Характер

- **Легенда** — из `persona.txt` (см. «Своя легенда»). Что он бот, все знают — это никому не мешает.
- **Своя жизнь.** Каждое утро бот расписывает свой день по легенде — где он и что делает, — и «где он сейчас»
  меняется в течение дня; в выходные день другой. Плюс 1–2 события дня в конкретное время: он узнаёт о них,
  только когда время пришло, и в затишье может рассказать в чат. Сюжет продолжается и слушает чат:
  советы друзей и то, что бот сам про себя рассказал, идут в следующие серии.
- **Настроение.** Каждые ~25 сообщений бот «прислушивается к себе»: в духе, на кураже, скучает, задет, обиделся,
  устал. Проходит само за 6 часов.
- **Отношения.** С каждым свои. Плюс — за внимание (болтали, ржали, звали), минус — только за настоящую неприязнь
  (гонят из чата, просят удалить). Мат и подколы — норма, за них не минусует. Обиды остывают на шаг за 4 дня.
- **Кодекс** сильнее характера и сделан частью персонажа, а не «правилами сверху»: мам не трогает, с девчонками
  шутит как со всеми, но без пошлятины, не гонит на национальность и ориентацию, никакой пошлятины про школьников.
  Если подбивают — отшучивается в своём стиле, без нотаций и слов про ИИ.

## Узнаёт в лицо

- **Записаться:** скинуть в беседу своё фото с подписью `/face` (или ответить `/face` на своё фото, где ты один).
  Пара фото с разных ракурсов — узнаёт увереннее. Запомнить можно только себя.
- **Что даёт:** бот знает, кто на присланном фото («на фото: Дима (слева), Катя (справа)»), подписи к мемам —
  про тех, кто на картинке, `/edit Дима` — эдит из фото и кружочков с ним.
- **Приватно:** всё считается локально (OpenCV: YuNet находит лица, SFace делает «отпечаток»), никуда не уходит.
  Хранятся только отпечатки записавшихся; чужие лица не запоминаются. `/face забудь` — стереть своё лицо и отметки.
- Модели (~40 МБ, Apache 2.0, OpenCV Zoo) качаются сами при первом запуске в `data/models/`.
- Лучше промолчать, чем назвать чужим именем: если лицо похоже на двоих или похоже слабо — бот не угадывает.

## Эдиты

Монтаж в духе CapCut-шаблонов «фонк-велосити»: нарезка под бит, замедления и ускорения, вспышки, тряска, зум,
подписи — всё собирается локально через ffmpeg.

- **Из чего:** фотки, видео и кружочки из беседы. Фоном бот рассматривает их (4 кадра из каждого видео) —
  что на кадре и годится ли; из видео берёт самые живые куски. Свои мемы в эдиты не берутся.
- **Треки:** стартовая библиотека фонка (MATADORA, Murder In My Mind, Close Eyes, Sahara, Metamorphosis и др.)
  качается с YouTube при первом запуске; у каждого трека заранее посчитаны темп и дроп. `/track название` — добавить.
- **Как попросить:** `/edit`, `/edit дача`, `/edit матадора` или словами: «бот, сделай эдит про шашлыки под матадору».
- **Итоги недели:** по воскресеньям вечером — эдит из того, что скинули за неделю.
- Треки чужие: для своей беседы нормально, публично выкладывать эдиты не стоит. `EDITS=0` — выключить.
- `python preview_edit.py матадора` — собрать эдит в файл, ничего не отправляя в чат.

## Необязательное: Яндекс

Без ключей эти функции просто выключены. Ключ и ID каталога — в [Yandex AI Studio](https://aistudio.yandex.ru)
(`YANDEX_SEARCH_API_KEY`, `YANDEX_FOLDER_ID`).

- **Картинки из интернета** (Яндекс Картинки, как @pic) — по контексту или `/pic`. ~0,9 ₽ за картинку.
- **Голосовые → текст** (SpeechKit): бот понимает голосовые и кружочки. ~0,65 ₽ за минуту. `VOICE=0` — выключить.
- **Голос бота** (SpeechKit) с мемными эффектами: бурундук, демон, робот, пьяный, рация, эхо, перегруз, злая,
  шёпот, диктор, быстро. ~0,1 ₽ за реплику. `TTS=0` — выключить.
- **Свежие мемы:** раз в сутки — шпаргалка из [Мемепедии](https://memepedia.ru) (работает и без ключа) и поиска Яндекса.

## Загрузить старую переписку

1. **Telegram Desktop** → чат → ⋮ → «Экспорт истории чата», формат HTML, отметить фото и видео.
2. `.venv/bin/python import_history.py "~/Downloads/Telegram Desktop/ChatExport_..."`
3. В экспорте нет id беседы, поэтому история «ждёт»: как только бот увидит сообщение в беседе с тем же
   названием (и она разрешена), подхватит историю и соберёт по ней летопись.

Повторный импорт дублей не создаёт. `--dry-run` — только посчитать.

## Чтобы работал 24/7

Бот должен постоянно крутиться там, где установлен и залогинен Claude Code или Codex. Например, на Linux — systemd:
```ini
# /etc/systemd/system/memebot.service
[Service]
WorkingDirectory=/home/you/meme-bot
ExecStart=/home/you/meme-bot/.venv/bin/python bot.py
User=you
Restart=always
[Install]
WantedBy=multi-user.target
```
`sudo systemctl enable --now memebot`. На маке — launchd или просто открытая вкладка терминала (пока мак не спит).
База, импорт, треки и модели лежат в `data/` — её и бэкапить.

## Проверка без Telegram

```bash
.venv/bin/python smoke_test.py               # прогон всего бота на фейковом Telegram (ИИ подменён)
SMOKE_AI=1 .venv/bin/python smoke_test.py    # + один настоящий ответ через твою подписку
.venv/bin/python preview.py                  # мемы на тестовой картинке и видео → preview/
```

## Что важно знать

- Видео больше 20 МБ бот не скачает — лимит Telegram для ботов.
- Медиа, увиденные ботом, хранятся как `file_id` (файлы остаются в Telegram); фотки из импорта — в `data/media/`.
  `/forget да` стирает память чата.
- Свои мемы бот в мемы не берёт (без рекурсии): узнаёт их по отправителю, file_id и «отпечатку» картинки.
- Свои шрифты можно положить в `fonts/` (см. `fonts/README.md`).
